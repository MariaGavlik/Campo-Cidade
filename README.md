# Campo-Cidade
agrinho 2025
Sou a criadora do projeto Campo Cidade, uma plataforma digital que desenvolvi com o objetivo de explorar e provocar reflexões sobre as relações entre o campo e a cidade. A ideia surgiu a partir de uma inquietação pessoal: como esses dois mundos, aparentemente tão distintos, se conectam, se influenciam e, muitas vezes, se distanciam?

No site, proponho uma investigação visual e conceitual sobre os fluxos, tensões e complementaridades entre os ambientes urbano e rural. Busco levantar questões sobre sustentabilidade, modos de vida, produção de alimentos, identidade cultural e pertencimento. O projeto também é uma tentativa de romper com estereótipos e dicotomias simplistas, convidando o visitante a perceber os cruzamentos sutis e profundos entre esses territórios.

No meu site serão abordados temas como a acessibilidade a água, energia rural e produção.

ESTRUTURA DO PROJETO:
Utilizei html, css e boodstrap para realizar esse projeto. 

DESCRIÇÃO:
Contem uma página inicial relatando relações entre campo e cidade
1- Acessibilidade a água: falará sobre a a cessibilidade e a relão entre campo cidade nesse tema
2- Energia rural: falará sobre a energia rural e como pode-se encontra-lá
3- Produção: Falará sobre produção.
